# Engineering Reporting

将原始工作材料重组为适合汇报、总结、述职和晋升场景的高质量结构化内容；也可把已经形成结论的复盘改写成面向特定读者的材料。

## 何时使用

当用户希望把零散、原始、素材型内容整理为更正式、更适合管理阅读或评审阅读的表达时，使用本 Skill。典型场景包括：

- 把零散笔记整理成管理汇报
- 把项目过程材料整理成阶段总结
- 把会议纪要、妙记或录屏提炼成老板可快速扫读的摘要
- 把已经形成结论的项目复盘改写成向上汇报版本
- 把成果条目、项目经历整理成自评或晋升材料
- 从执行记录中提炼影响力、复杂度、方法论和能力成长

当用户需要分析已完成工作的系统模式、判断因果并决定下次保留/改变/停止什么时，使用 `management-retro`；本 Skill 只负责把已经形成的复盘结论改写成适合读者的材料。

## 本 Skill 适合产出的内容

本 Skill 适合帮助用户产出如下结果：

- 管理汇报
- 高管摘要
- 项目总结
- 基于既有复盘结论的管理材料
- 自评材料
- 晋升材料
- 用于绩效、述职或答辩的代表案例叙事

## 核心表达原则

1. 先确认读者、材料用途和需要支持的决定，再选择结构。区分谁在阅读、谁有权决定、谁负责执行；同步材料要写清需要谁判断或采取什么行动。
2. 保留事实的来源和状态：用户提供、来源支持、实测、估算、推断、假设或待确认。估算不改成精确事实。
3. 将结果、行动、判断和建议分开；只提炼材料能支持的影响、复杂度、贡献和能力。
4. 输出适合读者快速扫读的版本；不要为了套用模板而补造因果、数字或“战略价值”。
5. 缺少关键数据时，给出待补字段及计算口径。若来源之间冲突，保留各自来源并标为待确认，不擅自平均或选边。

## 工作流程

1. 识别目标场景。
   - 管理汇报
   - 项目总结
   - 高管摘要
   - 自评材料
   - 晋升材料
   - 已完成结论的项目复盘改写

2. 提取源材料中的关键信号，并记录来源、时间、口径和证据状态。
   重点提取：
   - 背景与目标
   - 关键动作
   - 核心结果与业务价值
   - 风险、阻碍与取舍
   - 协同与 owner 角色
   - 可复用的方法、机制或模板

3. 进行叙事重组。
   用以下视角重组素材：
   - 结果
   - 影响
   - 复杂度
   - 影响范围
   - 判断与取舍
   - 方法论沉淀
   - 能力成长

4. 输出最合适的结构化版本。
   如果用户未指定格式，则根据任务意图自动选择最接近的输出形式。
   如果用户指定字数或篇幅上限，先按交付语言和用户指定的计数范围实际核算；若范围未说明，默认只计算正文并在有歧义时说明口径。留出约 10% 余量，压缩背景与修饰，不删掉会改变决定的证据状态、权限边界或限制条件。未核算前不要声称符合硬性上限。
   汇报来自材料或公开来源时，不添加材料未支持的细节。特别是事故汇报，要区分已报告的即时缓解、残余影响/恢复时间和“已防止复发”的结论；只陈述来源明确支持的动作与效果。若来源只说流量改道等动作，就准确写出该动作，不推断影响完全停止或风险已消除。

5. 补充缺失信息提示。
   如果量化结果、影响范围或复杂度证据不足，要明确指出，并建议用户补充。

## 默认输出格式

### A. 管理汇报版
- 一句话概述
- 背景与目标
- 核心进展
- 结果与业务影响
- 当前风险或待解决问题
- 下一步计划
- 需要的支持

### B. 项目总结版
- 项目背景
- 目标与挑战
- 关键动作与判断
- 结果与影响
- 经验教训
- 后续优化建议

### C. 高管摘要版
- 结论先行
- 最重要的 3 件事
- 业务/组织影响
- 当前主要风险或决策点
- 建议的下一步动作

### D. 晋升 / 自评版
- 职责范围与 owner 角色
- 代表案例
- 关键结果
- 处理过的复杂问题
- 跨团队影响力
- 沉淀的方法或机制
- 能力成长
- 为什么支撑更高一级职责

## 输入处理建议

本 Skill 适合处理如下输入：

- 妙记链接或妙记摘要
- 会议纪要
- 项目笔记
- 周报 / 月报 / 季报草稿
- 项目复盘文档
- 成果条目
- 零散自评素材
- 晋升材料草稿

如果素材太散或目标不明确，优先补齐以下信息：
- 目标读者是谁
- 期望输出格式是什么
- 时间范围是什么
- 希望重点强调结果、复杂度、影响力还是带人能力

## 边界情况

### 如果没有量化结果
不要编造数据。应当：
- 谨慎描述定性影响
- 明确指出“若补充量化结果会更有说服力”
- 给出建议补充的指标方向

### 如果素材只有动作没有价值
要主动把表达从“做了什么”提升为：
- 解决了什么问题
- 促成了什么变化
- 降低了什么风险
- 提升了什么效率
- 沉淀了什么机制

### 如果素材用于晋升
必须尽量提炼：
- 范围
- 模糊性
- 协同复杂度
- 影响范围
- 可复用价值
- 与更高层级要求的匹配度

### 如果素材用于老板或高层阅读
要更压缩，优先突出：
- 发生了什么关键变化
- 为什么重要
- 当前要关注什么
