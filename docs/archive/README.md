# Maintainer archive

This directory keeps the repository's internal research, evaluation records, project-description draft, and design/implementation notes for provenance. These files are not part of the installable skill packages and are not the user-facing catalog. Git commit history remains unchanged.

- `blog/` — project-description draft for later publication.
- `methodology/` — source mapping, evaluation records, and portfolio reviews.
- `research/` — competitor, demand, public-case, and method-source research.
- `superpowers/` — repository design records and execution plans.

Installable user packages live only under `skills/<skill-name>/`. The maintained method references required by an individual skill remain inside that skill's own directory.
